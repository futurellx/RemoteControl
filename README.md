# RemoteControl

一个使用 C++ 编写的 Windows 远程控制学习项目，基于 MFC、WinSock 和 IOCP 实现图形界面与网络通信，可用于本机回环测试，以及宿主机与虚拟机之间的控制实验。

## 项目组成

- **RemoteClient（控制端）**：输入被控端地址，查看远程文件目录、显示远程桌面并发送操作指令。
- **RemoteCtrl（被控端）**：监听 TCP 连接，处理文件、截图及鼠标等控制命令。

## 主要功能

- 连接测试、磁盘和目录浏览。
- 远程文件下载、打开和删除。
- 远程桌面截图显示与鼠标控制。
- 锁屏与解锁指令。

## 开发环境

Windows 10 / 11，Visual Studio 2022（MSVC v143）。安装“使用 C++ 的桌面开发”工作负载、C++ MFC 组件和 Windows SDK。

## 编译与运行

1. 使用 Visual Studio 打开 `RemoteCtrl.sln`，选择 `Debug | x64` 并生成解决方案。
2. 在被控机器上运行 `RemoteCtrl.exe`，保持服务端控制台开启，默认监听 TCP 端口 `9527`。
3. 在控制机器上运行 `RemoteClient.exe`，填写被控机器的 IPv4 地址和端口，点击“连接测试”。
4. 连接成功后，可点击“查看文件信息”浏览目录，或点击“远程监控”查看桌面并操作鼠标。

本机测试使用 `127.0.0.1:9527`；宿主机控制虚拟机时，在虚拟机中运行被控端，并在控制端填写虚拟机的可达 IPv4 地址。

重新生成前，请先停止 Visual Studio 调试并退出旧进程，避免运行中的 EXE 无法被链接器覆盖。服务端控制台中按回车可结束当前服务。

## 目录结构

```text
RemoteCtrl.sln       Visual Studio 解决方案
RemoteClient/        控制端：MFC 界面、通信与图像显示
RemoteCtrl/          被控端：IOCP 服务、命令处理与屏幕采集
```

项目用于已授权设备上的学习与实验，目前仍在调试完善中。
